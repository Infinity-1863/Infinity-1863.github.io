Current direction

Universal optimization for large language models on edge devices

The active work is shifting from these earlier AL devlogs toward a universal system for optimizing large language models on edge devices.

The goal is to make large-model execution more practical locally so user data can stay closer to the device, improving privacy and reducing exposure of sensitive information to external services.
