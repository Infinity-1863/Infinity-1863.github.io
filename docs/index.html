What this is

Bounded self-learning under supervision

AL is an early research prototype for studying whether bounded agents can improve from diagnosis-only supervision under objective verification.

The system follows a strict protocol: the agent acts first, an objective verifier determines success or failure, and the teacher may only diagnose after failure. Teacher execution is not allowed, and patch-shaped teacher outputs are rejected.

Core protocol

Diagnosis-only supervision

Agent acts first
→
Verifier checks result
→
Teacher diagnoses only after failure
→
Patch-shaped teacher outputs are rejected
→
Agent derives repair or procedure
→
Replay or near-transfer gate
→
Procedure memory promoted

Real-repo evidence

Narrow repair, honest blocking

On 5 real upstream clone tasks, AL repaired 2 narrow bugs and safely blocked or localized 3 harder cases.

All 5 tasks were verified red before AL ran.

There were no destructive failed patch loops in the reported real-repo evaluation. The current signal is not broad coding competence; it is bounded repair plus disciplined blocking.

Main text

Current evidence includes 55 bounded fixture families, 8 OSS localization-only cases, 5 real upstream clone tasks, 0 false learning, 0 false success, and one FastAPI planner bridge case where AL moved from localization to verifier-passing repair and near-transfer without a live teacher.

Safety constraints

What the system is not allowed to do

  • Teacher cannot execute tasks.
  • Patch-shaped teacher outputs are rejected.
  • Objective verifier is the source of truth.
  • Procedures are promoted only after replay or near-transfer success.
  • Blocked states become structured localization evidence.

Limitations

Current boundaries of the evidence

  • Current results are bounded and partly fixture-driven.
  • Real upstream repair success is 2/5.
  • Localization is stronger than repair planning.
  • More third-party repos and physical T2/T3 transfer tasks are needed.
