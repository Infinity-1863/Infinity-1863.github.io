# Constrained Self-Learning Agents Site

This repository now hosts a small research-style site for:

`Constrained Self-Learning Agents`

The site presents AL as:

- a research prototype for constrained self-learning agents
- an empirical benchmark for diagnostic supervision
- a bounded evidence-driven system with explicit limitations

The public site lives under `docs/`.

Structure:

- `docs/index.html`
- `docs/style.css`
- `docs/script.js`
- `docs/evidence/CANONICAL_EVIDENCE_SUMMARY.md`
- `docs/evidence/no_teacher_execution_protocol.md`
- `docs/evidence/real_repo_eval_5.md`
- `docs/evidence/oss_localization_8.md`
- `docs/evidence/fastapi_planner_bridge.md`
- `docs/evidence/limitations.md`

The root `index.html` is only a redirect to `docs/` so existing root-based Pages deployments keep working.
